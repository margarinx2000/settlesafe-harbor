Lifecycle — invoice #0, on-chain proof

Every step below is a real transaction on ME Beta Testnet. Each hash links straight to its transaction page on the testnet explorer and can also be copied.

⚖ Dispute branch (supported by the contract, not exercised in run #0)

From Funded or Delivered, either party can raise_dispute — funds stay locked — and the named arbiter settles with resolve_dispute { release_to_seller: true | false } → Released (seller paid) or Refunded (buyer paid back). Safety rails: the seller can claim_after_review once the review window expires, anyone can trigger refund_after_deadline if the seller never delivers, and a cancel_invoice is possible while still Created.
